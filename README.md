## Lab Overview
This repository investigates the molecular effects of the PiZ missense mutation in *SERPINA1* and compares it with an artificially generated 1-nucleotide deletion variant.

### Mutation Summary
| Variant | Type | Effect |
|---|---|---|
| PiZ (c.1096G>A) | Missense substitution | Glu366Lys → protein misfolding & retention |
| 1-bp Del (c.298del) | Frameshift deletion | Truncated protein at ~123 aa → complete loss of function |
